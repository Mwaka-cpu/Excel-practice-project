# Excel-practice-project
## Excel Sales Data Analysis Project 
### project overview
  this data analysis project aims to provide insights and informative dashboards of the sales data over time.By analyzing the sales value performance per region, sales channel and sales person I seek to identify trends and data driven make recomendations.

  ###Tools
   Excel
   ### 1.Data Transformation
   -Uploaded data to excel
   -Inspection of any missing values (none)
   -Data cleaning and formating - formated the sale_dates to excel starndard dates
   - Verified the sales_value and sales_quantity are numeric values

     ### 2. Statistical Analysis
 - aimed at finding the Totol and averge values for the sales_value and the sales_quantity
 - Added a sheet and named it 'Statistical Analysis'-Inserted pivot tables into the sheet to find the statistics

     ### 3. Data Analysis
  -aimed to find the sales_value per region, sales_channel, sales person and per sale_month
  -Added a sheet and named it 'Data analysis'-inserted pivot tables into the sheet to complete the analysis by draging 
   the sales_value to the values field and region, sales_channel,sales person id and sale_date to the rows respectively

  ### 4. Data Visualization
  - Added a new sheet 'Visualizatins'
  - created bar charts to show the sales_value per region and sales_channel using pivot tables.
  - Repeated the same using pie charts
  - Used a trend line to sales_value performance over time

    ### 5. Conclusion
    -North America leads with $1,080,783, followed closely by South America an asia
    -The highest-performing salesperson was ID 846 and generated $9,9956.
    -In-store sales channel toped followed very closely by Direct sales channel.
    - Sales peaked on Febuary and August and showed sharp decline in December.
